# AI Resume ATS Evaluator
## Overview
The AI Resume ATS Evaluator is an automated tool designed to help recruiters and hiring managers evaluate resumes based on their alignment with a specific job description. Using advanced Natural Language Processing (NLP) techniques, this tool compares resumes to job descriptions, calculates the similarity, and provides a score representing how well the resume fits the job role. It also generates word clouds for a visual analysis and allows recruiters to send interview invitations directly.

## Features
- PDF Resume Parsing: The tool allows users to upload resumes in PDF format, which are parsed and cleaned for analysis.

- Keyword Extraction: Keywords from both the uploaded resumes and the provided job description are extracted and compared.

- Cosine Similarity Evaluation: The tool computes the semantic similarity between the resume and job description using sentence embeddings generated by the Sentence-Transformer model (all-MiniLM-L6-v2).

- ATS Score: Based on the cosine similarity and keyword overlap, an ATS score is calculated for each resume, providing a percentage match to the job description.

- Word Cloud Visualization: Word clouds are generated for both the job description and the most frequent keywords in the resumes, helping to visualize the content focus.

- Email Interview Invitation: Allows the recruiter to send email invitations to selected candidates for interviews based on their ATS score.

## How It Works
- Resume Upload: Upload your resume(s) in PDF format using the Gradio interface.

- Job Description Input: Enter the job description text into the system. The tool uses this text for comparison with the uploaded resumes.

- Evaluation: The tool processes the resumes and calculates an ATS score based on semantic matching (using cosine similarity) and keyword overlap.

## Results: You will see an ATS score for each resume, indicating how closely it matches the job description. A word cloud for both the job description and top-ranked resume will also be generated.

## Interview Invitation:
If you want to send an interview invitation, simply input the candidate's email, and an automated email will be sent with the job description and a prompt to confirm interview availability.

## Key Technologies Used
Python: The core programming language for the project.

Gradio: Used for creating the interactive web interface.

Sentence-Transformers: A library for generating sentence embeddings and calculating cosine similarity.

PDFPlumber: Used for parsing resumes in PDF format.

NLTK: Used for stopword removal and text preprocessing.

WordCloud: Generates word clouds for visualization of keywords.

SMTP: Used for sending interview invitation emails.

## Installation
- Clone the repository:

git clone https://github.com/Panchadip-128/JobFit-AI-Multi-feature-ATS-System-Web-app
cd AI-Resume-ATS-Evaluator

- Install the required dependencies:
pip install -r requirements.txt

- Run the application:
python app.py
Visit http://0.0.0.0:7860 in your browser to interact with the application.

File Structure
app.py: The main file that runs the Gradio interface and backend logic.

requirements.txt: Lists all the necessary dependencies for the project.

README.md: This file.

assets/: Folder containing any static assets (e.g., logos, images).

Usage
Upload Resumes
Drag and drop or browse for PDF files that contain the resumes you wish to evaluate.

Enter Job Description
Copy and paste the job description text into the provided input field.

Evaluate
After uploading the resumes and entering the job description, click on the Evaluate button to generate the ATS scores and word clouds.

Interview Invitation
If you want to invite a candidate for an interview, enter the candidate’s email address, and the tool will send an email with the job description and interview details.

Example Output
ATS Score: The system will return a percentage score for each resume, indicating how closely it matches the job description.

Word Cloud: Visual representation of keywords from both the resume and job description.

Email Sent: Confirmation of the email invitation sent to the candidate.

## Notes
- The tool does not require any pre-existing datasets. All analysis is performed dynamically on the uploaded resume and provided job description.
- It uses NLP techniques such as sentence embeddings for semantic comparison and cosine similarity to calculate the match between the job description and the resume.
- Stopword removal and keyword extraction are based on NLP libraries like NLTK.
- Email functionality works locally but may fail on Hugging Face Spaces due to restricted network access to SMTP servers (Huggingface Free tier limitations)
